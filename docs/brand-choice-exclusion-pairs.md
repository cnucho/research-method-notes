# 브랜드 간 선택·배제 경쟁구도 계산식

## 입력

분석할 구입 브랜드 집합을 \(S\)라 둔다. 모든 빈도는 사람 수이며, 열은 **최종 구입 브랜드**, 행은 **비교 후 배제 브랜드**다.

- \(n_i\): 브랜드 \(i\)를 구입한 사람 수. 배제 브랜드에 관계없이 해당 구입 열의 전체 사례수.
- \(x_{ij}\): 브랜드 \(i\)를 구입하고 브랜드 \(j\)를 배제한 사람 수. 행렬에서 **열 \(i\), 행 \(j\)**의 값.
- \(N_S=\sum_{i\in S}n_i\): 분석 대상 브랜드 구입자 수. 원조사의 전체 표본 수와 구분한다.

## 하나의 정규화 규칙

모든 표시 비율에 같은 분모 \(N_S\)를 쓴다.

\[
\boxed{
\text{구입점유율 }P_i=100\frac{n_i}{N_S},\qquad
\text{방향비율 }D_{i\to j}=100\frac{x_{ij}}{N_S},\qquad
\text{쌍 경쟁비율 }C_{\{i,j\}}=D_{i\to j}+D_{j\to i}
=100\frac{x_{ij}+x_{ji}}{N_S}\quad(i\ne j)
}
\]

방향 표기 \(i\to j\)는 **\(i\) 구입·\(j\) 배제**를 뜻한다. 한 브랜드 쌍 \(\{i,j\}\)에는 반대 방향의 관측값 두 개가 있다. 따라서 브랜드가 \(k\)개이면 쌍은 \(k(k-1)/2\)개, 방향값은 \(k(k-1)\)개다.

## 도식 구성

- 원 하나는 구입 브랜드 하나를 나타내고, 원의 크기 또는 옆의 수치로 \(P_i\)를 표시한다.
- 브랜드 쌍당 연결선 하나를 그린다. 선의 굵기는 \(C_{\{i,j\}}\), 양방향의 수치 표기는 각각 \(D_{i\to j}\)와 \(D_{j\to i}\)를 쓴다.
- 대각선 \(x_{ii}\)는 서로 다른 브랜드 간 연결선에 넣지 않는다.
- 분석 집합 밖의 배제 브랜드를 나타내는 잔여 사례수는 \(r_i=n_i-\sum_{j\in S}x_{ij}\)로 구한다. 동일 브랜드 셀과 잔여 사례는 별도 구성비 막대나 주석에 표시한다.

## 검산 및 해석

- \(n_i=\sum_{j\in S,\,j\ne i}x_{ij}+x_{ii}+r_i\)를 열별로 확인한다.
- 원표의 셀 합계와 열 전체 사례수가 어긋나면 \(r_i\)는 **열 전체에서 표시된 셀을 뺀 잔여값**으로 정의하고 차이를 기록한다.
- 이 비율은 분석 대상 구입자 전체에서 차지하는 비율이다. 특정 브랜드 구입자 **내부** 비율이 필요하면 별도로 \(100x_{ij}/n_i\)를 계산하고 분모를 명시한다.
- 한 응답자가 여러 배제 브랜드에 중복 기록될 수 있는 자료라면 쌍 합계를 고유 인원 수라고 부르지 않는다.
